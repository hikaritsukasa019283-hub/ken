전체 흐름

토큰 id는 임베딩을 거쳐 같은 구조의 블록 @@n_layers@@개를 차례로 통과하고, 마지막에 로짓이 돼요. 블록끼리 다른 점은 K/V를 직접 만드는지, FFN에 몇 비트를 쓰는지뿐이에요.

블록 하나

블록은 어텐션을 먼저 돌리고, 그 결과를 정규화한 h를 공유 FFN과 Expert Graph에 동시에 넣어요. 두 출력과 잔차를 모두 더한 값이 다음 블록의 입력이에요.

Expert Graph

토큰마다 Domain → Operation → Control 순서로 expert를 하나씩 골라요. 앞 expert의 잠재 벡터가 뒤 expert의 입력이라서 @@r_domain@@ → @@r_op@@ → @@r_ctrl@@로 좁아지고, 각 단계가 자기 출력을 잔차에 더해요.

KV 공유와 비트 수

@@n_layers@@개 층 중 @@n_owner@@개만 K/V를 만들고 @@n_sharer@@개는 읽기만 해요. 비트 수는 공유 FFN만 층에 따라 달라서, 앞뒤 @@edge@@개 층은 3-bit, 가운데는 2-bit예요.

파라미터와 메모리

파라미터의 @@expert_share@@가 Expert Graph인데 토큰당 expert는 3개만 실행해서 활성은 @@active@@예요. 2-bit 양자화 덕에 같은 모델이 @@ram@@에 들어가요.
